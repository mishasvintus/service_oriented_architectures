## Сервис статистики (Statistics Service)

**Зона ответственности:**
- Сбор метрик взаимодействия
- Анализ пользовательской активности
- Формирование отчетов
- Хранение исторических данных

**Границы сервиса:**
✓ Подсчет лайков/просмотров
✓ Агрегация статистики
✓ Предоставление API для аналитики
✗ Не хранит исходный контент
✗ Не управляет бизнес-логикой

**Ключевые сущности:**
- `LikeStat` - статистика реакций
- `ViewStat` - метрики просмотров
- `CommentStat` - анализ комментариев
