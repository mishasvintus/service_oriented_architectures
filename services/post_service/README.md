# Сервис контента (Post Service)

**Зона ответственности:**
- Создание/редактирование постов
- Управление комментариями и медиа
- Модерация контента
- Организация древовидных комментариев

**Границы сервиса:**
✓ Публикация и хранение контента
✓ Валидация медиа-вложений
✓ Управление жизненным циклом постов
✗ Не считает статистику
✗ Не управляет пользователями


**Ключевые сущности:**
- `Post` - основной контент
- `Comment` - система обсуждений
- `Media` - медиавложения к постам
