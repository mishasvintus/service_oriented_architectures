
# Сервис пользователей (User Service)

**Зона ответственности:**
- Регистрация и управление учетными записями пользователей
- Аутентификация и управление сессиями
- Хранение персональных данных и профилей
- Управление ролями и правами доступа

**Границы сервиса:**
✓ Регистрация/авторизация
✓ CRUD операций с профилями
✓ Генерация токенов сессий
✗ Не хранит контент пользователей
✗ Не анализирует активность

**Ключевые сущности:**
- `User` - базовая информация аккаунта
- `UserProfile` - расширенные данные профиля
- `Session` - активные сессии пользователей
