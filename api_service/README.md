## API Gateway

**Зона ответственности:**
- Единая точка входа для всех клиентских запросов
- Маршрутизация запросов к соответствующим сервисам
- Аутентификация и авторизация на уровне API
- Балансировка нагрузки и кэширование ответов
- Обработка и трансформация ошибок

**Границы сервиса:**
✓ Валидация входящих запросов
✓ Распределение нагрузки между инстансами
✓ Агрегация ответов микросервисов
✗ Не содержит бизнес-логики
✗ Не хранит данные пользователей/контента
