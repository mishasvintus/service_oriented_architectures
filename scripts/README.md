# 🔧 Scripts Directory

Эта директория содержит все вспомогательные скрипты проекта, организованные по категориям.

## 📁 Структура

```
scripts/
├── README.md                    # Эта документация
├── run_tests.sh                 # Главный скрипт запуска тестов
├── database/                    # 🗄️ Скрипты для базы данных
│   └── init-multiple-db.sh      # Инициализация множественных БД в PostgreSQL
└── testing/                     # 🧪 Тестовые скрипты
    ├── TESTING.md               # Документация по тестированию
    ├── run_tests.py             # Главный Python скрипт тестов
    ├── test_unit.py             # Запуск unit тестов
    ├── test_integration.py      # Запуск интеграционных тестов
    └── test_kafka.py            # Запуск Kafka тестов
```

## 🚀 Использование

### Тестирование
```bash
# Из корня проекта
scripts/run_tests.sh [unit|integration|kafka|all]
```

### База данных
- `database/init-multiple-db.sh` - автоматически используется Docker Compose для создания отдельных БД для каждого сервиса

## 📝 Принципы организации

1. **По функциональности**: каждая подкатегория скриптов в своей директории
2. **Документация рядом**: README и документация в той же директории, что и скрипты
3. **Удобство запуска**: главные скрипты доступны из корня проекта
4. **Переносимость**: все пути относительные, скрипты работают из любой директории

## 🔄 Добавление новых скриптов

При добавлении новых скриптов:

1. **Определите категорию**: database, testing, deployment, etc.
2. **Создайте подкатегорию** если нужно: `scripts/deployment/`
3. **Добавьте документацию**: обновите этот README
4. **Сделайте исполняемым**: `chmod +x scripts/category/script.sh`
5. **Используйте относительные пути**: скрипты должны работать из корня проекта

## 📋 Планируемые категории

- `scripts/deployment/` - скрипты развертывания
- `scripts/monitoring/` - скрипты мониторинга
- `scripts/backup/` - скрипты резервного копирования
- `scripts/migration/` - скрипты миграции данных
